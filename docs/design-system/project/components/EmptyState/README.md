# EmptyState

An invitation, not an apology: label, a Space Mono line naming the space, one sentence on why it's worth filling, one primary action. Ground: a quiet dot field in `line` inside a dashed `line-strong` frame. No illustrations, no mascots. Viewers (who can't add) get the sentence without the button.

**First steps** (home): a single row "First steps · 3 of 4 · next: Invite your team →" that opens the steps still to do; no accent border or fill, finished steps hidden. It disappears once all are done or it is closed.
