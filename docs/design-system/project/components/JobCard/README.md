# JobCard

The Jobs board (`/jobs`): open positions that companies post for freelancers. Company as eyebrow, status (Open, Filled `off`, Applied `info`), the role and gig in Space Mono, place / dates / places as the facts row, the fee in Space Mono with its unit, the note, then Message and Apply (at most two buttons; the rest in ⋯). On the Jobs board a job is a hairline row, not a card. Filled jobs stay visible a day, `muted`, with no Apply.
