# U6: A QR and print date on every print

## Changelog
### Added
- Every print now has a small QR code in its bottom corner, with the date and time it was printed
  beside it. Scanning it opens the same page live in AVX, so an old paper copy is easy to spot.
  The link is AVX's own address: it needs a sign-in and the same access as the page, so a printed
  sheet never shares anything publicly. On the call sheet, input list, stage plot, patch and DMX
  sheets, light plot, system, power plan, packing list and rehearsal report.

### Changed
- The "Printed <date>" line on those prints moved into the new footer beside the QR (same words).

## Roadmap
Upkeep row "A QR and print date on every print (D32)": built. How it works: one shared
`<PrintFooter />` (src/components/PrintFooter.jsx) at the end of each print's sheet; the link comes
from `printLink()` (src/lib/printLink.js): the app's own address for the current page, with any
query value that looks like a secret dropped. Later prints (rigging report RG4, work areas 20b)
get it by adding `<PrintFooter />`.

## Pending: test lines (section 2)
- Print the call sheet (or Save as PDF), scan the QR in the corner with a phone: it opens the call
  sheet in AVX after sign-in; someone not on the gig gets "Call sheet not available".

## Pending: new questions (section 3)
- The quote print (/quote/:id/print), the wrap-up and the reports pages have no QR: the quote goes
  to clients (who can't open AVX), and the others are reports rather than gig sheets. Assumed: leave
  them out; add `<PrintFooter />` later if wanted.
- The sweep script refuses tags shorter than 3 characters, so `npm run e2e:sweep -- u6` (the tag in
  the worker brief) fails; worker tags should be 3+ characters (e.g. `u6x`) or the limit lowered.
