# S08: MVR and GDTF for the light plot and DMX patch (step 14)

## Changelog
### Added
- **Import MVR** in the DMX patch and the light plot: an .mvr file from Vectorworks, grandMA3, Capture or another lighting program brings its fixtures in one go, with type, mode, channels, DMX address, fixture number, place and height. You pick the catalogue item for each fixture type (AVX suggests one), type the channels where the file doesn't say, and see what will happen before anything is saved. New hanging positions appear on the light plot; importing the same file again updates the fixtures instead of adding them twice.
- **Export MVR**: the gig's light plot and DMX patch as an .mvr file for the lighting desk or the drawing program, with the fixture types' GDTF files inside.
- **GDTF fixture types on catalogue items** (Inventory item → ⋯ → "GDTF fixture-type file"): the modes and their channel counts, and the file's weight and power for the item.
- A help guide, "Bring a rig in from MVR, and send it back", and the words MVR and GDTF in the glossary.
### Connected
- Catalogue: weight and power from GDTF files go on the item, so the light plot's power and weight per position (and later P1 and RG1) use them; matched fixtures take them automatically.
- DMX patch: picking an item offers its GDTF modes and fills the footprint.
- Light plot: imported fixtures keep their places; new positions are added; the import adds the DMX patch and light plot to the gig if missing.
- Gig equipment: matched fixtures count for "Add to equipment".
- Import fix panel (IM1): not connected, because IM1 isn't built yet; the MVR import has its own match step.
