# S07: A1 speaker library (step 13)

## Changelog
### Added
- **Speaker specs on catalogue items.** A "Speaker specs" part in the item form: kind of speaker, sensitivity, maximum SPL, dispersion (horizontal × vertical), frequency range, impedance, amplifier channels per cabinet and the datasheet they come from. Weight and power stay where they were. The item page lists them.
- **Rigging data** (centre of gravity, pickup points, bumper/frame limits, source), copied as printed from the manufacturer. Always shown as "needs a second person's check before use"; the line array tool (RG3) will add that check.
- **Presets for ten models**, typed from the manufacturers' own documents with the document, version and date: L-Acoustics K2, Kara II, X12, KS28; d&b V8, Y10P, V-SUB; RCF HDL 30-A; Meyer Sound LEOPARD; NEXO GEO M1220. What a document doesn't give stays empty.
- Help: ⓘ hints on every new field, the "Speaker specs" term, a tip in the sound system calculator guide.
### Connected
- **Sound system calculator (F4):** pick a catalogue speaker per source and its maximum SPL and horizontal angle come from the catalogue instead of typed numbers; "Update from catalogue" when the item changes.
- **Import wizard:** speaker columns are guessed; a "Speaker preset" column (e.g. "L-Acoustics K2") fills the empty cells; new refusals: unknown preset, value outside the limits, highest frequency below the lowest.
