# StatTile

Inventory reports, dashboard counts, hours totals. On the home, Key numbers sit in a `SwipeRow`: a sideways scroll-snap row on a phone (the next tile shows cut off), a 3-column grid from 768px. `label`, the value in Space Mono 24px with its unit, one mono note that says what it's made of. No sparkline unless the trend is the point; no up/down colours for money.
