# Dialog

`ui.jsx` `Modal`. Square `panel` with a `line-strong` edge on a flat 72% black scrim — **no blur, no shadow**. Title in Space Mono 16px as a question that names the consequence; body says what changes and what stays; actions bottom-right, the confirming one last and worded as the act ("Remove from gig", not "OK"). Irreversible deletes (gig, organisation) use the danger zone flow (`danger.*`: type the name, wait seconds). Enter fade + rise 10px / 250ms. On phone, forms open as full-height sheets.
