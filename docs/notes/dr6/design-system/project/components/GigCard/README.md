# GigCard

A row in the gig list (Dashboard, My work). Date block in Space Mono (weekday · day · month) separated by a `line`; name in Space Mono 14px; one row of **status + label chip + venue · dates**; on the right, the thing this viewer needs: **their call time** (crew), the crew avatars (PM/admin), or their gig role when it's another company's gig in My work.

Gig status words: Draft (dashed empty square), Confirmed (`accent-text` square), Active (`info`), Completed and Archived (`off`, muted). Rows sit in a stack with 1px `line` between them; hover is `hover` fill, not a lift.
